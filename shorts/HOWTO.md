# ショート動画 台本づくり How to

制作者の知識を正確に引き出しながら、ショート動画の台本・ナレーション・素材リストを作るための、題材を問わない手順。
題材固有の情報（固有名詞、参考サイト、シリーズの決まりごと）はここに書かず、各動画のフォルダに置く（実例：`shiren6-tessoku/howto.md`、`shiren6-dorobou/images.md`）。

## 基本方針

- 内容（事実・主張・ノウハウ）は制作者のもの。AIは構成・整形・不足の指摘・音声向けの調整を担当する
- 頼まれていない内容を、確定稿のように書かない。案を出すときは仮（🟡）と明示する
- 確認できない事実は推測で埋めない
- 一度に完成を目指さず、小さく出して直してもらう

## 手順

### 1. 依頼内容の確認
- 題材・伝えたいこと・視聴者を一文で言い直して確認する
- 比喩や造語は「実物か比喩か」を最初に確認する（取り違えると全体のやり直しになる）
- 音声（話者・口調）、形式（縦横・長さ）は、制約が本当にあるかを聞く。シリーズものは前作の `script.md` 冒頭を引き継ぎ、違えば指示をもらう

### 2. 事実の確認
- 固有名詞や数値は、まず検索で確認を試す
- 確認できた誤りは、聞き返さずに直し、直したことを報告する
- 確認できないものは、制作者の言葉を一次情報として扱う。同じ名前を何度も「要確認」にしない
- 推測で項目や数値を作らない。必要なのに無い情報は、制作者に聞くか「要確認」と書いて残す

### 3. 型（構成）を決める
- 典型例：一覧型（オープニング → 項目 → まとめ/CTA）、問題解決型（悩み → 原因 → 対処）、手順型（結論 → 手順 → 注意点）、比較型（A/B → 観点ごとの違い → おすすめ）
- 項目ごとの繰り返し単位を決める（例：状況 → 理由 → 対処、名前 → 使い道）
- 型は途中で変えてよい。変えたら全体を見直す

### 4. 内容を少しずつ受け取る
- 項目ごとに受け取る。途中で切れた入力は補完せず、続きを聞く
- 意味を変えずに口調だけ整える。制作者の言い回しはできるだけ残す
- 視聴者が知らない前提が省かれていたら、聞き出して行として足す
- 破棄を求められたら以降使わない

### 5. 未提供部分は仮で置く
- 未提供部分は案を書いて仮（🟡）、確定部分は確定（✅）と書き分ける
- 仮の部分を一覧にして見せ、差し替えてもらう。修正文をもらったら、語尾だけ整えてそのまま反映する

### 6. 音声合成向けに整える（既定はVOICEVOX）
- 話者に合わせて語尾をそろえる
- 数字・記号・難読語・造語は、ひらがな/カタカナに置換する（例：「87%」→「はちじゅうななパーセント」）
- 画像やカットを切り替える位置で行を分け、1行1音声にする。間が詰まるなら読点を足す
- 読みの最終確認は、制作者が実際に聞いて行う

### 7. 素材リストを作る
- 背景動画：パートごとの内容と長さの目安（リピート前提なら数秒〜十数秒）
- 画像：番号・内容・パート・表示タイミング（言い始める瞬間など）を表にする
- テロップ・背景・ロゴなどの任意素材
- 参考画像を集めて見せてよい（任意）：`images.tsv` に画像URLと出典を書き、`python3 shorts/tools/fetch_images.py shorts/<動画名>/images.tsv` で一覧画像を作る。画像はコミットしない（`ref_images/` は .gitignore 済み）。使用可否は制作者が判断する

### 8. 通しで確認して保存する
- 部分修正のあとは、全文を通して見せる
- 残った確認事項は `script.md` の末尾に書く

## 成果物（`shorts/<動画名>/`）

| ファイル | 中身 |
|---|---|
| `script.md` | 冒頭に条件（音声・形式・型・凡例 ✅/🟡）、通し台本、素材リスト、確認事項 |
| `narration.txt` | 音声合成に貼る用（1行1音声、読み置換済み） |
| `images.tsv` / `images.md` | 任意。参考画像の一覧・取得手順・出典 |
| `howto.md` | 任意。その動画だけの進め方や気づきがあるとき |

## 次工程（動画の組み立て）

1. `narration.txt` を1行ずつ音声合成し、書き出す
2. 音声の長さを測り、パートごとの時間を決める
3. 背景動画・画像・テロップを配置する
4. 必要なら字幕（SRT）を音声の長さから作る
5. 確認事項を解消して書き出す

## 依頼テンプレート

```
題材：
伝えたいこと（比喩なら比喩と明記）：
視聴者：
音声：（話者・口調／前作と同じ）
形式・長さ：（制約があれば）
型：（なければ相談）
項目：
 1.
 2.
素材：使える動画・画像の有無
```

## チェックリスト

- [ ] 比喩・造語の意味を確認した
- [ ] 事実は確認済みか、制作者の情報か、「要確認」のどれかになっている
- [ ] 仮（🟡）の部分が一覧できる
- [ ] 音声向けの読みを置換した
- [ ] 素材リストに表示タイミングがある
- [ ] 通しで読み返した

## このHOWTOの直し方

- 学びは、該当する手順の一行として一般化して書く（「〇〇の回で…」という記録の形では足さない）
- 題材固有の内容（ゲーム名、固有名詞、参考サイト、表示の好み）は、各動画の `script.md` や `howto.md` に書く
- 新しい行を足す前に、既存の行の言い換えで済まないかを確かめる
