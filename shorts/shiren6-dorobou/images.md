# 確認用画像（意図せず泥棒になってしまう理由）

制作者が素材を選ぶための**確認用**。画像そのものはリポジトリにコミットしない（`ref_images/` は .gitignore 済み）。
動画に使うかどうか、使ってよいかは制作者が判断する（攻略サイト・ゲーム会社の素材のため）。

## ローカルで画像をそろえる（引き継ぎ手順）

```
git pull
python3 shorts/tools/fetch_images.py shorts/shiren6-dorobou/images.tsv
```

- `shorts/shiren6-dorobou/ref_images/` に13枚と、番号つきで並べた `_sheet.png` ができる
- Pillow がない場合は画像だけ保存される（シートが欲しければ `pip install pillow`）
- 取得に失敗した行は、表示される出典ページを開いて手動で保存する

## 分かったこと・注意

- **壺・草・巻物・杖は、ゲーム内でも種類ごとに同じアイコン**。攻略サイトにも個別の絵はない。
  「水鉄砲の壺」「高跳び草」などを見せたいときは、ゲーム内の持ち物画面やお店の値札（名前つき）を録画・スクショするのがよい
- 「高跳び草といやし草が同じ200ギタン」「未鑑定品を買う場面」「水鉄砲が商品に当たる場面」も、攻略サイトに画像がない。ゲーム内で撮影する
- **要確認：「風遁忍者」**
  AppMedia のモンスター一覧（シレン6）の忍者は、火遁・水遁・木遁・金遁・土遁の5種で、「風遁忍者」は見つからなかった。
  「丸太を操りぶつけてくる。丸太がぶつかると吹き飛ばされる」のは**木遁忍者**（AppMedia 木遁忍者種）。
  台本は制作者の表記（風遁忍者）のまま。木遁忍者のことなら台本とナレーションを直す

## 集め方（次の動画でも同じ）

1. 台本の画像リスト（`script.md`）から、モンスター・アイテム・罠の名前を拾う
2. 攻略サイトの一覧ページで名前を探し、ページ内の `<img>` の `alt`（例：`シレン6_木遁忍者_icon`）と `src` から画像URLを取る
   - AppMedia（appmedia.jp/shiren6/…）：モンスター一覧、罠一覧、アイテム一覧、泥棒のやり方
   - 神ゲー攻略（kamigame.jp/shiren6/…）：店主の種類、泥棒のやり方
3. `images.tsv` に「番号・保存名・掲載名・画像URL・出典ページ・用途」を書く
4. `fetch_images.py` で取得し、`_sheet.png` を制作者に見せる
5. 調べる途中で台本の事実と食い違う点が出たら、台本は直さずに「要確認」として制作者に聞く
