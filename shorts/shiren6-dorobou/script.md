# 意図せず泥棒になってしまう理由（風来のシレン6）

- 音声：VOICEVOX ずんだもん（語尾「〜のだ」）／やさしい解説調（前回までと同じ想定。違えば指示を）
- 形式：縦型（ショート）／長さ指定なし
- 型：一覧型（オープニング → 項目 → まとめ）。各項目は「状況 → 理由 → 対処」
- 記号：✅確定（制作者の内容）／🟡仮（Claudeの案）

## 台本

### オープニング 🟡
- 泥棒するつもりなんてないのに、気づいたら店主に襲われていたこと、あるのだ？
- 実は、意図せず泥棒になってしまうパターンがあるのだ。
- 3つ紹介するのだ。

### 1. 水鉄砲の壺をアイテムに当てる
- 状況 ✅：水鉄砲の壺は、アイテムに当てると、食べ物が腐ったり、修正値が下がったりするのだ。
- 理由 ✅（🟡言い回しは要確認）：でも、店の外から商品に当てると、その瞬間に泥棒扱いになるのだ。
- 対処 ✅：トドの壺も、期待して押すなら、シレンから3マス以上離してから押すのだ。
- テロップ 🟡：（2敗）

### 2. 風遁忍者の特技を食らう
- 状況 ✅：風遁忍者は、丸太の罠と同じように、シレンを移動させる特技を使ってくるのだ。
- 理由 ✅：商品を持ったまま食らうと、泥棒になることがあるのだ。
- 理由の補足 🟡：お店の外まで、飛ばされてしまうからなのだ。
- 対処 ✅：ちゃんと封印の杖を振ってから、倒すのだ。
- テロップ 🟡：（1敗）

### 3. 高跳びする商品を使う
- 状況 ✅：高跳び草や、魔物部屋の巻物など、使った時点で高跳びをする商品を使うと、泥棒判定になるのだ。
- 理由 ✅：特に高跳び草は、祝福されていると200ギタンで、いやし草と同じ値段なのだ。
- 理由の補足 🟡：だから、いやし草だと思って飲むと、泥棒になってしまうのだ。
- 対処 🟡：お店の中では、正体の分からない草や巻物を、使わないようにするのだ。
- テロップ 🟡：（n敗）

### まとめ 🟡
- お店の中では、商品の扱いに、気をつけるのだ。
- みんなの泥棒事故も、コメントで教えてほしいのだ。
