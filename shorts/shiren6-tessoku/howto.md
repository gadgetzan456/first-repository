# 台本の作り方 How to（シレン6「風来人の鉄則」制作メソッド）

ショート動画の台本を「制作者の知識を正確に引き出しながら」作るための手順。今回のやり取りから整理した。次の動画にも使い回せる。

## 全体の流れ

1. 題材とコンセプトを確認する
2. 事実が確認できるか調べる（できなければ推測で埋めない）
3. 動画の型（構成テンプレート）を決める
4. 制作者から内容を少しずつ受け取る
5. 足りない部分は「仮」で置いて、後で差し替える
6. 音声合成（VOICEVOX）向けに文章を整える
7. 素材リスト（動画・画像）を作る
8. 通しで確認し、ファイルにまとめる

## 1. 題材とコンセプトを確認する

- 最初の依頼は短くてよい。「何についての動画か」「何を伝えたいか」を一文で言い直して確認する
- 今回の例：「血のマニュアル」は実在の本ではなく、「やられて学んだ“やってはダメ”が心に刻まれたもの」という比喩だった。最初に誤解したので、比喩か実物かを早めに確認すること
- 長さの制約（ショートは60秒以内、など）が本当に必要かも確認する。今回は不要だった

## 2. 事実が確認できるか調べる

- ゲームの固有名詞（項目名、敵名、数値）は、Web検索で確認できるか試す
- 確認できなければ、**推測で項目や数値を作らない**。制作者から受け取る
- 今回は「鉄則」の公式一覧が見つからなかったため、制作者の知識を一次情報として扱った
- 表記があやしい固有名詞（例：「がいこつまてん」）は、台本に入れたうえで「確認が必要」と明記して残す

## 3. 動画の型を決める

今回の型（各状況をこの順で繰り返す）：

1. **タイトル**：その状況を一文で全画面表示（ナレーションでも軽く読む）
2. **理由**：実際のプレイ動画を短くリピート再生しながら、なぜそうなるかを説明
3. **対処**：テロップ「対処」を出して、どうすればよいかを軽く説明

全体は オープニング → 状況を並べる → エンディング（コメントを促す）。
最初に「状況→理由」の2段で組み、あとから「対処」を足した。型は途中で変えてよい。

## 4. 内容を少しずつ受け取る

- 一度に全部をもらおうとせず、状況ごとに受け取る（今回は4状況）
- 途切れた入力（「状況1：当たれば勝つけど」）は補完せず、「続きを送ってください」と返す
- 破棄を求められたら、保存していないことを伝えて以降は使わない
- 受け取った文は、意味を変えずに口調だけ整える

## 5. 足りない部分は「仮」で置く

- 理由や対処が未提供のときは、自分の案を書いて**「仮（🟡）」を明示**する
- 仮の内容は表にまとめて見せ、制作者に直してもらう（今回は「対処法だけまとめた表」を作った）
- 確定した部分は「確定（✅）」と書き分ける。何が確定済みかが一目で分かる
- 仮の内容は、制作者の修正文を受け取ったら、語尾だけ整えてそのまま反映する

## 6. VOICEVOX向けに整える

- 話者に合わせて語尾を決める（今回はずんだもん想定：「〜のだ」）。話者は最初に確認する
- 口調は制作者の希望に合わせる（今回は「厳しくない感じ」＝やさしい解説調）
- 読み間違えやすい部分を置換する
  - 数字や記号：「87%」→「はちじゅうななパーセント」、「？」→「はてなマーク」
  - 難読語や造語：ひらがなに置換（「ンドゥバ種」→「んどぅば種」）
- 読みの最終確認は制作者がVOICEVOXで聞いて行う。違和感があればひらがなに直す
- 間が詰まる場合は読点を増やす。切り替えのテンポは、1文ずつ別音声ファイルにして編集で合わせる
- 画像を切り替える箇所（敵の名前など）は、名前ごとに読点で区切り、1行ずつの音声にする（narration.txt）

## 7. 素材リストを作る

台本が固まったら、制作者が用意するものを一覧にする。

- **背景動画**：パートごとに内容と長さの目安（リピート前提なので数秒〜十数秒）
- **画像**：登場する敵やアイテムなど。表示タイミング（名前を言い始める瞬間）も記載
- **背景画像・ロゴ**：任意

## 8. 通しで確認し、ファイルにまとめる

- 会話では部分ごとに直していくが、最後に全文を通して見せる
- 確認が残っている点（名称、具体名など）を台本の末尾に書いておく
- 保存先は `shorts/<動画名>/`。構成：
  - `script.md`：通し台本、素材リスト、確認事項
  - `narration.txt`：VOICEVOXに貼る用（1行1音声）
  - `howto.md`：このメソッド

## 次工程（ローカルで動画を作る）

1. `narration.txt` を1行ずつVOICEVOXに入力し、音声ファイルを書き出す
2. 各音声の長さを測り、`script.md` のパートごとに時間を割り当てる
3. 背景動画と画像を用意し、各パートでリピート再生するように配置する
4. タイトルと「対処」のテロップを入れる
5. 必要なら字幕（SRT）を、音声の長さから作る
6. 確認が残っている点（「がいこつまてん」の正式名称など）を解消してから書き出す

## 再利用用の依頼テンプレート

```
題材：
伝えたいこと（比喩なら比喩と明記）：
音声：VOICEVOX（話者：   ）／口調：
長さ：（制約があれば）
状況・項目：
 1. タイトル／理由／対処
 2. ...
素材：使える動画・画像の有無
```

## 今回の学び（失敗と対処）

- 比喩を実物と取り違えた → 「実在する本ではなく心の中のもの」と説明を受けて修正
- 勝手に作った台本は破棄を求められた → 内容は制作者が決める。AIは構成・整形・不足の指摘に徹する
- 公式情報が見つからなかった → 推測で埋めず、制作者の知識を一次情報にした
