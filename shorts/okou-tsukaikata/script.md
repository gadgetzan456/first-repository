# お香の使い方（風来のシレン6）

- 音声：VOICEVOX ずんだもん（語尾「〜のだ」）／やさしい解説調
- 形式：縦型（ショート）／長さ指定なし
- 型：一覧型（オープニング → 項目 → まとめ）
- 記号：✅確定（制作者の内容）／🟡仮（Claudeの案）

## 台本

### オープニング 🟡
- お香って、正直捨てがちなのだ。
- でも実は、ゲームを変えうるポテンシャルがあるのだ。

### 1. やまびこのお香 ✅
- やまびこのお香は、魔法を反射する状態になるお香なのだ。
- 幸せの杖でのレベリングや、一時しのぎの杖での泥棒だけじゃないのだ。
- がいこつまてん種の強力な状態異常を、反射できるのだ。
- ポリゴン種やゲイズ種の魔法も、反射できるのだ。

### 2. 目配りのお香 ✅
- 目配りのお香は、持ち物をなくさない状態になるお香なのだ。
- ぬすっトド系にしか使えないように見えるのだ。
- でも、アイテムをはじいてくる荒らし種や、ケンゴウ種の対策にもなるのだ。

### 3. 視界不良のお香 ✅
- 視界不良のお香は、視界が常に1マスになる、使いづらそうなお香なのだ。
- でも、効果範囲が絶大なのだ。
- アークドラゴンやみだれ大根を、完全に対策できるのだ。
- 大部屋モンスターハウスで焚くと、こっちはモンスターの場所が見えるのだ。
- なのに、モンスターはシレンを認識できないのだ。

### 4. 攻めのお香・守りのお香 🟡
- 攻めのお香と守りのお香は、使い道が少ないのだ。
- だから、ギタンに変えちまうのだ。（具体的な金額は言わない）

### まとめ 🟡
- 捨てる前に、使い道を考えてみてほしいのだ。
