# 個人的 不快だったカード3選

> 状態：下書き。3枚のカード情報は HearthSim のカードデータ（hsdata `CardDefs.xml`、build 253216）から取りました。
> ナーフの履歴は、hsdata に残っている過去のビルドのデータを比べて調べました（日付はそのデータが更新された日）。セット名は Blizzard の公式ニュース・ショップの表記です。
> メソッドどおり、公式カードライブラリでカード本体と照らし合わせてから確定してください。

## ネタ帳
### 1枚目
- カード名：影宝石商ハナー（英：Shadowjeweler Hanar）
- 収録セット：灰に舞う降魔の狩人（本体セット）
- クラス・種類：ローグ／レジェンドミニオン（2マナ 1/4。発売時は 1/5）
- 効果：自分が秘策を手札から使用した後、別のクラスの秘策1つを発見する。
- 不快ポイント：秘策を使うたびに、ハンター・メイジ・パラディンの秘策が増えていく。相手はローグの秘策だけでなく、他クラスの秘策まで警戒させられる。発売時は体力5で、2マナなのに倒しにくかった
- その後：パッチ17.2.1（2020年5月）で 1/5 → 1/4 にナーフされた
- 使う画像：card_1
- メモ：秘策を持つクラスはハンター・メイジ・パラディン・ローグの4つだけ（カードデータで、集めて使える秘策をクラス別に数えて確認）
- メモ：フレーバーテキストは「うちの影宝石ガチャは全部シークレットだぜ」

### 2枚目
- カード名：キングプラッシュ（英：King Plush）
- 収録セット：ウィズバンのワクワクワークショップ（本体セット。カードIDが TOY_357 で、ミニセットの MIS_ ではない）
- クラス・種類：ハンター／レジェンドミニオン（9マナ 6/6、獣）
- 効果：突撃、雄叫び:これより攻撃力が低いミニオン全てをそれぞれの所有者のデッキに戻す。
- 不快ポイント：並べた盤面が（攻撃力5以下なら）まとめてデッキに戻され、そのまま突撃の6点で殴られる。倒されるのではなくデッキに戻るので、断末魔も発動しない
- その後：パッチ32.2.4（2025年5月）で効果が「雄叫び:相手の体力が15以下の場合、自身を除く全てのミニオンを所有者のデッキに戻し、突撃を獲得する。」に変わり、環境から消えた
  - パッチ35.0.0（2026年3月）でスタン落ちし、それに合わせてナーフが解除されて元の効果に戻った
- 使う画像：card_2
- メモ：フレーバーテキストは「この子はふわふわすぎて、だっこしたら死んじゃうかも！」。映画『怪盗グルーの月泥棒』の「It's so fluffy I'm gonna die!」が元ネタ？【要確認】

### 3枚目
- カード名：とりかへばや（英：Switcheroo）※「とりかえばや」ではなく「へ」
- 収録セット：深淵に眠る海底都市（本体セット。英語名 Voyage to the Sunken City。ミニセット「潮の玉座」ではない）
- クラス・種類：プリースト／呪文（5マナ、コモン。発売時は3マナ）
- 効果：ミニオンを2体引く。それらの体力を入れ替える。
- 不快ポイント：デッキのミニオンを2体だけにして、確実に引く組み合わせで悪用された
  - 引く2体：ツインフィン・フィンツイン（3マナ 2/1、急襲、雄叫び:これのコピーを1体召喚する。同じセットの中立レア）と、10マナ 12/12 のレジェンド（当時スタンダードで使えた10マナ 12/12 のレジェンドは、コアセットの破壊者デスウィングだけ）
  - 体力を入れ替えると、ツインフィンは2/12になる。3マナで出すと、コピーと合わせて2/12の急襲が2体並ぶ
  - 対処札を引けていれば楽に勝てるが、無いときはそのまま負ける。理不尽
- その後：パッチ29.0.0（2024年3月、ペガサス年の開始）で 3マナ → 5マナにナーフされた
  - 効果文は発売時から「それらの体力を入れ替える」で、ナーフで変わったのはマナコストだけ（データ上）
  - このパッチは深淵に眠る海底都市がスタンダードから落ちた時期と重なる
- 使う画像：card_3（とりかへばや）、card_3_sub1（ツインフィン・フィンツイン）、card_3_sub2（破壊者デスウィング）
- メモ：カード名は古典『とりかへばや物語』（男女が入れ替わる話）が元ネタと思われる【要確認】
- メモ：体力を入れ替えた後に付く効果の名前は「君の攻撃力と体力は。」（映画『君の名は。』のパロディと思われる【要確認】）
- メモ：フレーバーテキストは「鯨サイズの金魚1匹と金魚サイズの鯨100匹、戦うならどっち？」

## 演出メモ
- 8：今の公式画像は5マナなので、マナの部分に「当時3マナ」のテロップを重ねる
- 11：「体力12」「2体」を色を変えて強調。コピーが出るところで画面を揺らす
- 12：「対処札」のテロップを出し、手札に無い様子（空っぽの手札に×印）をオリジナルで描く
- 8：字幕は公式どおり「とりかへばや」と表記する。読み上げは VOICEVOX で「とりかえばや」と読むよう、読みを指定する
- 10：引いた2体の体力の数字が、左右に入れ替わるアニメーション（入れ替わった数字は色を変えて強調）
- 4：ハンター・メイジ・パラディンの秘策マークが「？」付きで順に浮かぶ（クラス名は文字テロップで出し、オリジナルの演出にする）
- 6：相手側のミニオンが1体ずつデッキに吸い込まれる動き（オリジナル演出）
- 7：「6点」は色を変えて強調。キングプラッシュが画面手前に突っ込んでくる揺れ
- 2枚目の効果音は1枚目・3枚目と重ならないようにする（1枚目の不快ポイントがブブーなので、7はイラッ）
