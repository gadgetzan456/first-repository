# 3連LEDライト フローチャート

`light.c` の処理を図にしたものです。GitHub 上ではそのまま図として表示されます。

## 全体像（状態遷移）

ライトがとりうる状態と、どの操作で移るかを示します。点滅中の短押しと、点滅していないときの長押しは無視されます（状態は変わりません）。

```mermaid
stateDiagram-v2
    state "全消灯" as OFF
    state "LED1 点灯" as L1
    state "LED2 点灯" as L2
    state "LED3 点灯" as L3
    state "点滅（2周目・短押し無効）" as BLINK {
        state "全消灯 0.5秒" as BOFF
        state "全点灯 0.5秒" as BON
        [*] --> BOFF
        BOFF --> BON
        BON --> BOFF
    }
    [*] --> OFF : 電源ON
    OFF --> L1 : 短押し2回
    L1 --> L2 : 短押し2回（LED1を消してすぐLED2）
    L2 --> L3 : 短押し2回（LED2を消してすぐLED3）
    L3 --> BLINK : 短押し2回（LED3を消してすぐ点滅）
    BLINK --> OFF : 3秒長押し
```

## 起動処理（`main() / light_init()`）

初期化のあとは何もせず、処理はすべて10msecのタイマ割り込みで行います。

```mermaid
flowchart TD
    A([電源ON]) --> B["GPIO・タイマを初期化"]
    B --> C["light_init()<br/>スイッチの確定状態 = OFF<br/>一致カウント・押下時間 = 0<br/>通常モード・全消灯・短押し0回"]
    C --> D["10msecタイマ割り込みを許可"]
    D --> E["メインループ（何もしない）"]
    E --> E
```

## 10msec タイマ割り込み（`light_tick_10ms()`）

10msecごとに3つの処理をこの順で呼びます。点滅処理を先に置くことで、点滅開始直後の1周期もちょうど0.5秒になります。

```mermaid
flowchart TD
    S([10msecタイマ割り込み]) --> A["点滅処理<br/>update_blink()"]
    A --> B["スイッチ判定（チャタリング防止）<br/>debounce_switch()"]
    B --> C["押下時間の計測<br/>update_press_time()"]
    C --> E([割り込み終了])
```

## スイッチ判定（チャタリング防止）（`debounce_switch()`）

生入力が確定状態と3回続けて違ったときだけ、確定状態を切り替えます。離したことが確定した時点で、3秒未満なら短押しになります。

```mermaid
flowchart TD
    S([スイッチ判定]) --> R["生入力を読む"]
    R --> Q1{"生入力 = 確定状態？"}
    Q1 -->|はい| Z["一致カウント = 0"] --> E([終了])
    Q1 -->|いいえ| I["一致カウント +1"]
    I --> Q2{"一致カウント ≥ 3？"}
    Q2 -->|いいえ| E
    Q2 -->|はい| U["一致カウント = 0<br/>確定状態 = 生入力"]
    U --> Q3{"確定状態は ON？"}
    Q3 -->|はい：押された| P["押下時間 = 0<br/>長押し済み = いいえ"] --> E
    Q3 -->|いいえ：離された| Q4{"長押し済み？"}
    Q4 -->|はい| E
    Q4 -->|いいえ：3秒未満| SP[["短押し処理"]] --> E
```

## 押下時間の計測（`update_press_time()`）

押している間、10msecずつ数えます。3秒に達した時点で、離すのを待たずに長押しとして処理します。

```mermaid
flowchart TD
    S([押下時間の計測]) --> Q1{"確定状態が ON<br/>かつ 長押し済みでない？"}
    Q1 -->|いいえ| E([終了])
    Q1 -->|はい| I["押下時間 +10msec"]
    I --> Q2{"押下時間 ≥ 3秒？"}
    Q2 -->|いいえ| E
    Q2 -->|はい| L["長押し済み = はい<br/>（離しても短押しにしない）"]
    L --> LP[["長押し処理"]] --> E
```

## 短押し処理（`on_short_press()`）

短押し2回ごとに、点いているLEDを消してすぐ次のLEDを点けます。LED3の次は、LED3を消してすぐ点滅（2周目）に入ります。

```mermaid
flowchart TD
    S([短押し処理]) --> Q1{"点滅中？"}
    Q1 -->|はい| X["何もしない（短押し無効）"] --> E([終了])
    Q1 -->|いいえ| C["短押し回数 +1"]
    C --> Q2{"短押し回数 = 2？"}
    Q2 -->|いいえ| E
    Q2 -->|はい| R["短押し回数 = 0"]
    R --> Q3{"LED3 が点灯中？"}
    Q3 -->|いいえ| Q4{"点灯中のLEDがある？"}
    Q4 -->|はい| OFF["そのLEDを消灯"] --> ON
    Q4 -->|いいえ：最初の1回| ON["すぐ次のLEDを点灯<br/>LED1 → LED2 → LED3"]
    ON --> E
    Q3 -->|はい| O3["LED3を消灯"]
    O3 --> B["すぐ点滅開始（2周目）<br/>モード = 点滅<br/>点滅カウント = 0<br/>全LED消灯の状態から始める"]
    B --> E
```

## 長押し処理（`on_long_press()`）

点滅中だけ意味があります。点滅していないときの長押しは何もせず、短押しの回数にも数えません。

```mermaid
flowchart TD
    S([長押し処理]) --> Q{"点滅中？"}
    Q -->|はい| N["通常モードに戻す<br/>全消灯・短押し0回<br/>短押しが有効になる"] --> E([終了])
    Q -->|いいえ| X["何もしない"] --> E
```

## 点滅処理（`update_blink()`）

点滅中は0.5秒（10msec × 50回）ごとに全LEDの点灯と消灯を入れ替えます。

```mermaid
flowchart TD
    S([点滅処理]) --> Q1{"点滅中？"}
    Q1 -->|いいえ| E([終了])
    Q1 -->|はい| I["点滅カウント +10msec"]
    I --> Q2{"点滅カウント ≥ 0.5秒？"}
    Q2 -->|いいえ| E
    Q2 -->|はい| T["点滅カウント = 0<br/>点灯と消灯を反転して<br/>全LEDに出力"]
    T --> E
```
