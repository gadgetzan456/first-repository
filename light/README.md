# 3連LEDライト（スイッチ1個）

マイコンの種類に依存しない C 言語の実装です。

| ファイル | 内容 |
|---|---|
| `light.h` / `light.c` | ライト本体（状態管理） |
| `test_light.c` | PC 上で動作を確かめるシミュレーションテスト |
| `simulator.html` | ブラウザで操作できるシミュレータ（`light.c` を JavaScript に移植） |

## 動作

1. 起動時は全LED消灯
2. スイッチを **2回短押し** するごとに LED1 → LED2 → LED3 の順に1つずつ点灯（前のLEDは消灯）
3. LED3 の次の2回短押し（2周目突入）で **全LEDが0.5秒ごとに点滅**、短押しは無効
4. 点滅中にスイッチを **3秒長押し** すると全消灯して起動時の状態に戻り、短押しが再び有効になる

### スイッチの判定

- 10msec 周期のタイマ割り込みで入力を読む
- チャタリング防止：**3回連続で同じ値** を読んだときに ON / OFF を確定
- 押下時間 3秒未満で離したら短押し（OFF確定時に判定）
- 押下時間が 3秒に達した時点で長押し（離すのを待たずに反応）。長押しのあとに離しても短押しにはならない

## 仕様の解釈（要確認）

指示に明記がなかったため、次のように決めています。違う場合は教えてください。

- 「1,2,3の順に点灯/消灯」は、2回短押しごとに点灯するLEDが1つずつ移っていく動きと解釈
- 「2周目」は LED3 の次（LED1 に戻るタイミング）で点滅に入る
- 2回の短押しの間隔に制限はない（何秒あいても2回目でカウント）
- 点滅していないときの長押しは何もしない（短押し回数にも数えない）
- 長押しで点滅を解除したあとは、全消灯・短押し0回の状態から再スタート
- OFF の確定も ON と同じく3回連続一致にしている

## マイコンへの組み込み

`light.h` の2つの関数をハードウェアに合わせて実装し、10msec タイマ割り込みから `light_tick_10ms()` を呼びます。

```c
#include "light.h"

bool hal_switch_is_on(void)                 { /* 押されていれば true（プルアップなら論理を反転） */ }
void hal_led_write(uint8_t index, bool on)  { /* index 0〜2 の LED を on/off */ }

void timer_10ms_isr(void)   /* 10msec 周期の割り込みハンドラ */
{
    light_tick_10ms();
}

int main(void)
{
    /* GPIO・タイマの初期化 */
    light_init();
    /* 割り込み許可 */
    for (;;) { }
}
```

## ブラウザで試す

`simulator.html` をブラウザで開くと、画面のスイッチをクリック（またはスペースキー）で押して動きを確かめられます。チャタリングの再現、内部状態（連続一致回数・押下時間・短押し回数）、生入力と確定後の波形も表示します。

## テスト

```sh
cc -std=c99 -Wall -Wextra -o test_light light.c test_light.c && ./test_light
```
