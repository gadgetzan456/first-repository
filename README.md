# 組子めいろ

指でなぞって解く、ランダム生成の格子迷路パズルです。

- ページ下部の「迷路作成」ボタンを押すとランダムな迷路が作られます。
- 鳥居(スタート)からドラッグして灯籠(ゴール)までなぞるとクリアになり、少し待つと次の迷路が自動的に生成されます(問題番号が進むにつれて迷路は少しずつ大きくなります)。
- 「迷路作成」ボタンはいつでも押せて、新しい迷路をやり直せます。

## 使い方

ビルド不要の単一HTMLファイルです。`index.html` をブラウザで直接開くだけで遊べます。

```
open index.html
```

または簡易サーバーで配信する場合:

```
python3 -m http.server
```

## 迷宮五十階

不思議のダンジョン系(シレン風)のターン制ローグライクです。`shiren-like.html` を直接ブラウザで開いて遊べます。

- 地下1階から地下50階まで、階ごとに自動生成されるダンジョンに挑みます。通路は基本的に幅1マスです。
- 矢印キー / WASD、または画面下の方向パッドで移動・向き変更をします。向いている方向にZキー(または「攻撃」ボタン)を押すと、その先に敵がいれば攻撃します(移動キーでの自動攻撃は廃止しました)。
- キーボードでは、Xキーを押しながら上下いずれか+左右いずれかを同時に押すと、その組み合わせの斜め方向(左上/右上/左下/右下)に移動できます。Xを押しながら上下・左右どちらか片方だけの入力は無視されます(q/e/cキーでの固定斜め移動も従来通り使えます)。
- 斜めに攻撃する際、対象との間に壁の角(直交する2マスのどちらか一方でも壁)がある場合は攻撃できません。これはプレイヤー・モンスターの双方に適用されます。
- 攻撃の視覚フィードバック:向いている方向の1マス先に、素手なら拳、武器装備中なら剣を振り下ろしたようなマークが約0.3秒表示されます。敵がいないマスへの「素振り」も可能で、ターンを1つ消費して敵も通常通り行動します(壁の角に阻まれている場合はマークも表示されずターンも消費しません)。
- 力尽きると地下1階からやり直しになる、いわゆる「不思議のダンジョン」系の一回限りの冒険です。
- 薬草・おにぎり・武器・盾・巻物などのアイテムを拾い、使用・装備・破棄ができます。強化の巻物は武器用・盾用に分かれています(出現比率2:1)。フロア生成時に床に置かれるアイテムは通路には出現せず、部屋の中にのみ配置されます。武器・盾は何も装備していない状態で拾うと自動的に装備されます(既に装備がある場合は通常通り持ち物に入ります)。
- 巻物は全部で6種類: 強化の巻物(武器/盾)・テレポートの巻物・明かりの巻物(この階の通路の形と敵の位置が、階を移動するまで分かるようになる)・メガシンカの巻物(100ターンの間、攻撃力が2倍になる)・真空切りの巻物(使用した部屋にいる敵全員にレベル×10のダメージ、部屋の外では不発)。巻物カテゴリ全体の出現重み合計は6種類に増やす前と変えていません(既存3種の重みを0.7倍にし、新規3種に再配分)。
- 満腹度、毒、経験値によるレベルアップ、10階ごとの強敵(ボス)などを実装しています。
- プレイヤーの最大HPは初期値23(前回設定の1.5倍)、敵・ボスの攻撃力は前回設定の0.8倍に調整しています。移動に伴う自然回復(10ターンごとにHP+2)は据え置きです。
- 敵を倒すと一定確率でアイテムをドロップします(雑魚敵はおよそ12〜35%、ボスは必ず装備品や巻物を落とします)。
- モンスターはフロア移動時だけでなく、行動するたびに低確率で新たに湧きます(1フロアあたりの上限あり)。
- モンスターハウス:地下4階以降、各フロアにつき1部屋だけ3%の確率で出現します。該当する部屋の床マスの7割にモンスターが配置され、アイテムも多めに置かれます。中のモンスターはプレイヤーがその部屋に足を踏み入れるまでは行動できず、入った瞬間に一斉に動き出します。
- モンスターごとに1つずつ固有の特殊能力を持ちます: スライム=分裂、巨大ネズミ=瀕死で逃走、コウモリ/大コウモリ=攻撃時に吸血、毒キノコ=毒、ゴブリン=目覚めると周囲の仲間を起こす、スケルトン=致命傷を1度だけ耐える(不死)、オーク=瀕死で攻撃力上昇、鎧武者=攻撃を受け流すことがある、妖術師=2マス先まで攻撃可能、死霊=壁をすり抜けて移動・攻撃、大鬼=会心率上昇、竜鱗の戦士=防御力貫通、深淵の魔物=低確率でプレイヤーの隣に瞬間移動。
- 冒険者はヒト型のキャラクターとして描画され、武器・盾を装備すると見た目にも反映されます。また移動方向を向くように立ち絵が回転します。
- モンスターも種族ごとに異なるシルエット(スライム・獣・翼竜・キノコ・幽霊・ローブ姿・人型など)で描画されます。
- 床と壁ははっきり見分けられるよう色を統一・コントラストを強めています。敵の色もより濃く・はっきりさせ、床や壁に埋もれないようにしています。
- 階段はRPGらしい、奥に向かって小さくなる段差のある下り階段の見た目にしています。
- 進行状況はブラウザの localStorage に自動保存され、途中で閉じても「続きから始める」で再開できます(力尽きるか制覇するとセーブは消去されます)。
