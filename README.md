# ブラウザミニゲーム集

ビルド不要・単一HTMLファイルで遊べるミニゲームをまとめたリポジトリです。各ファイルをブラウザで直接開くだけで遊べます。

## 🧱 特殊ブロック崩し (`block-kuzushi.html`)

定番のブロック崩しに「特殊能力」を足したアレンジ版です。

- マウス/指でパドルを操作し、クリックまたはスペースキーでボールを発射・レーザーを発射します。
- 一部のブロックには特殊能力が宿っています。
  - **爆発ブロック**: 破壊すると周囲のブロックを巻き込み連鎖的に爆発します。
  - **倍率ブロック**: 破壊すると一定時間スコアが2倍になります。
  - **お楽しみブロック**: 必ず能力アイテム(カプセル)を落とします。
  - **硬いブロック / 鋼鉄ブロック**: 2回当てないと壊れない、または一切壊れず避けて進む必要があります。
- 落ちてくるカプセルをパドルでキャッチすると、パドル拡大・縮小、ボール分裂、レーザー、キャッチ(吸着)、スロー/加速、残機+1、貫通する火球、スコアボーナスなど様々な効果が発動します(緑系は追い風、赤系は向かい風の効果です)。
- 残機は基本3機。すべて失うとゲームオーバーです。ハイスコアはブラウザにローカル保存されます。

## 🌀 組子めいろ (`index.html`)

指でなぞって解く、ランダム生成の格子迷路パズルです。

- ページ下部の「迷路作成」ボタンを押すとランダムな迷路が作られます。
- 鳥居(スタート)からドラッグして灯籠(ゴール)までなぞるとクリアになり、少し待つと次の迷路が自動的に生成されます(問題番号が進むにつれて迷路は少しずつ大きくなります)。
- 「迷路作成」ボタンはいつでも押せて、新しい迷路をやり直せます。

## 使い方

ビルド不要の単一HTMLファイルです。各ファイルをブラウザで直接開くだけで遊べます。

```
open index.html
open block-kuzushi.html
```

または簡易サーバーで配信する場合:

```
python3 -m http.server
```
