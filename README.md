# 組子めいろ

指でなぞって解く、ランダム生成の格子迷路パズルです。

- ページ下部の「迷路作成」ボタンを押すとランダムな迷路が作られます。
- 鳥居(スタート)からドラッグして灯籠(ゴール)までなぞるとクリアになり、少し待つと次の迷路が自動的に生成されます(問題番号が進むにつれて迷路は少しずつ大きくなります)。
- 「迷路作成」ボタンはいつでも押せて、新しい迷路をやり直せます。

## 使い方

ビルド不要の単一HTMLファイルです。`index.html` をブラウザで直接開くだけで遊べます。

```
open index.html
```

または簡易サーバーで配信する場合:

```
python3 -m http.server
```

## 迷宮五十階

不思議のダンジョン系(シレン風)のターン制ローグライクです。`shiren-like.html` を直接ブラウザで開いて遊べます。

- 地下1階から地下50階まで、階ごとに自動生成されるダンジョンに挑みます。通路は基本的に幅1マスです。行き止まりで終わる通路(壁に突き当たって何もない小さな枝道)は生成後に取り除いており、通路は必ずどこかの部屋につながります(部屋自体が行き止まりになるのは問題ないため、そのまま残ります)。また、構成上どこからも到達できない部屋が生まれることもありません。
- 移動・向き変更は矢印キー、または画面下の方向パッドで行います(右手で方向操作・左手でアクションキーという操作分担のため、WASDでの移動は廃止しました)。向いている方向にZキー(または「攻撃」ボタン)を押すと、その先に敵がいれば攻撃します(移動キーでの自動攻撃は廃止しました)。
- キーボードでは、Xキーを押しながら上下いずれか+左右いずれかを同時に押すと、その組み合わせの斜め方向(左上/右上/左下/右下)に移動できます。Xを押しながら上下・左右どちらか片方だけの入力は無視されます(q/e/cキーでの固定斜め移動も従来通り使えます)。方向キーを先に押してからXを押す・Xを先に押してから方向キーを押す、縦横どちらの押し順でも同じように斜め移動が成立します。
- 斜め移動は、壁の角(直交する2マスのどちらか一方でも壁)を挟んでいるとすり抜けられません。ただしスライム・コウモリ・大コウモリのような小柄なモンスターと、壁をすり抜ける死霊は例外としてこの制限を受けません(プレイヤーは常にこの制限を受けます)。
- 斜めに攻撃する際、対象との間に壁の角(直交する2マスのどちらか一方でも壁)がある場合は攻撃できません。これはプレイヤー・モンスターの双方に適用されます。
- 攻撃の視覚フィードバック:向いている方向の1マス先に、素手なら拳、武器装備中なら剣を振り下ろしたようなマークが約0.3秒表示されます。敵がいないマスへの「素振り」も可能で、ターンを1つ消費して敵も通常通り行動します(壁の角に阻まれている場合はマークも表示されずターンも消費しません)。
- 階段は乗っただけでは降りません(誤って踏んで進んでしまう事故を防止)。階段の上に乗った状態でZキー(または「攻撃」ボタン、乗っている間は「階段を降りる」表示に変わります)を押すと次の階へ進みます。
- 力尽きると地下1階からやり直しになる、いわゆる「不思議のダンジョン」系の一回限りの冒険です。
- 薬草・おにぎり・武器・盾・巻物などのアイテムを拾い、使用・装備・破棄ができます。強化の巻物は武器用・盾用に分かれています(出現比率2:1)。フロア生成時に床に置かれるアイテムは通路には出現せず、部屋の中にのみ配置されます。武器・盾は何も装備していない状態で拾うと自動的に装備されます(既に装備がある場合は通常通り持ち物に入ります)。
- ゲーム開始時、持ち物には大きなおにぎり(満腹度+75)を1つ持った状態でスタートします(序盤の空腹による餓死リスクを下げるため)。
- 投擲アイテムとして矢・石があります。Sキー(または「射撃」ボタン)で、装備中の投げ物を向いている方向へ投げます。矢は射程10マス・石は射程3マスで、命中すると矢は素手の通常攻撃と同じダメージ、石はその2倍のダメージを与えます(武器の攻撃力は乗りません)。命中率は通常攻撃と同じ78%で、外れると当たるはずだった敵のマスに落ちます。射程の途中で壁に当たった場合はその手前に落ち、着地先のマスに既に別のアイテムがある場合は投げたものはそのまま消えます。矢・石はまとめて1つの持ち物欄に収まり(所持上限99)、床に落ちている状態では複数個/複数本まとめて拾えます。何も投げ物を装備していない状態で拾うと自動的に装備されます(武器・盾と同様、既に装備がある場合は通常通り持ち物に入ります)。
- 巻物は全部で6種類: 強化の巻物(武器/盾)・テレポートの巻物(今いる部屋とは別の部屋へ飛ぶ)・明かりの巻物(この階の通路の形と敵の位置が、階を移動するまで分かるようになる)・メガシンカの巻物(100ターンの間、攻撃力が2倍になる)・真空切りの巻物(使用した部屋にいる敵全員にレベル×10のダメージ、部屋の外では不発)。巻物カテゴリ全体の出現重み合計は6種類に増やす前と変えていません(既存3種の重みを0.7倍にし、新規3種に再配分)。
- 満腹度、毒、経験値によるレベルアップ、10階ごとの強敵(ボス)などを実装しています。
- プレイヤーの最大HPは初期値23(前回設定の1.5倍)、敵・ボスの攻撃力は前回設定の0.8倍に調整しています。移動に伴う自然回復は5ターンごとに、その時点の最大HPの3%(最低1)を回復します(固定値ではなく最大HP依存にすることで、レベルアップ後も回復量が薄くなりすぎないようにしています)。
- 攻撃には命中判定があります(基本命中率78%)。プレイヤー→敵、敵→プレイヤーのどちらの通常攻撃にも同じ命中率が適用され、外れると1ターン消費するのみでダメージは発生しません。攻撃が外れた際は対象の頭上に「MISS」と表示され、ログを見なくても一目で外れたと分かるようになっています。また、敵がプレイヤーを攻撃する際は(命中・外れ問わず)プレイヤー側へ0.3マス分だけ踏み込んですぐ元の位置へ戻る動きをし、攻撃してきたことが見た目でも分かるようにしています。
- 敵を倒すと一定確率でアイテムをドロップします(雑魚敵はおよそ12〜35%、ボスは基本的に必ず装備品や巻物を落とします)。装備中の武器/盾と同じか、それより価値(攻撃力/防御力の上昇量)の低い武器/盾が抽選で選ばれた場合は、拾う意味がないため何もドロップしなかったことにします(他のアイテムが出やすくなるような振り直しは行いません)。この判定はフロア生成時に床へ直接置かれるアイテム(通常の部屋・モンスターハウスどちらも)にも同様に適用され、対象になった場合はそのマスには何も置かれません(こちらも振り直しはしません)。
- モンスターはフロア移動時だけでなく、行動するたびに低確率(3%)で新たに湧きます(1フロアあたりの上限あり)。この「徘徊モンスター」は必ずプレイヤーが今いる部屋以外の部屋に出現し、50%の確率でモンスターハウスの初期状態と同様の「睡眠状態」(その部屋にプレイヤーが足を踏み入れるまで行動できない)になります。残り50%は最初から普通に動けます。睡眠状態のモンスターは、プレイヤーがその部屋に入った瞬間に目を覚まします。
- モンスターハウス:地下4階以降、各フロアにつき1部屋だけ3%の確率で出現します(降り立った開始部屋も対象に含みます。テレポートの巻物で別の部屋へ逃げられるため、降り立った部屋がモンスターハウスでも詰みにはなりません)。該当する部屋の床マスの7割にモンスターが配置され、アイテムも多めに置かれます。中のモンスターはプレイヤーがその部屋に足を踏み入れるまでは行動できず、入った瞬間に一斉に動き出します。
- モンスターごとに1つずつ固有の特殊能力を持ちます: スライム=分裂、巨大ネズミ=瀕死で逃走、コウモリ/大コウモリ=攻撃時に吸血、毒キノコ=毒、ゴブリン=目覚めると周囲の仲間を起こす、スケルトン=致命傷を1度だけ耐える(不死)、オーク=瀕死で攻撃力上昇、鎧武者=攻撃を受け流すことがある、妖術師=2マス先まで攻撃可能、死霊=壁をすり抜けて移動・攻撃、大鬼=会心率上昇、竜鱗の戦士=防御力貫通、深淵の魔物=低確率でプレイヤーの隣に瞬間移動。
- モンスターの出現階層は「最低出現階層」のみが決まっており上限はないため、同じ種族が本来の出現階より深い階に紛れ込むこともあります。その場合はステータス(HP・攻撃力・防御力)が階層差に応じて強化されるだけでなく、10階層強くなるごとに体色も変化します(スライムとスライムベスのように、同じ種族でも階層帯によって色合いが違って見える)。そのモンスターが最初に出現する階層帯では元のデザイン通りの色のままです。
- 冒険者はヒト型のキャラクターとして描画され、武器・盾を装備すると見た目にも反映されます。移動方向は単純な回転ではなく、上下左右・斜め4方向の計8方向それぞれに専用の立ち絵(正面/背面/横向き/斜め向き)を用意しており、どの方向を向いてもきちんと立ってそちらを向いているように見えます(左右・斜め左右は鏡像反転で描き分け)。
- モンスターも種族ごとに異なるシルエット(スライム・獣・翼竜・キノコ・幽霊・ローブ姿・人型など)で描画されます。
- 床と壁ははっきり見分けられるよう色を統一・コントラストを強めています。敵の色もより濃く・はっきりさせ、床や壁に埋もれないようにしています。
- 床に落ちているアイテムは種類ごとに専用のビジュアルで描かれます:武器は剣、盾は盾のアイコン(どちらも素材ごとの色をそのまま使用)、巻物は忍者が使うような両端に軸のある巻物(種類ごとに紙の色や封の色が変わる)、薬草・毒消し草・全回復の薬などの「草」系アイテムは、どうぶつの森で家具をしまうと葉っぱになるようなシンプルな葉っぱアイコン、おにぎり・大きなおにぎりは白いご飯と海苔を巻いたおにぎりのイラスト、矢は鏃と羽根の付いた矢のイラスト、石は灰色のごつごつした岩のイラストで表示されます。
- 階段はRPGらしい、奥に向かって小さくなる段差のある下り階段の見た目にしています。
- 進行状況はブラウザの localStorage に自動保存され、途中で閉じても「続きから始める」で再開できます(力尽きるか制覇するとセーブは消去されます)。
- 力尽きたときの結果画面には、直前のダメージ原因に応じた専用の死亡セリフが表示されます。空腹・毒による死亡はそれぞれ専用の一言があり、モンスターに倒された場合はモンスターごとに異なる(コウモリなら「コウモリによって血を吸いつくされた。」など)セリフが表示されます。ボスに倒された場合もボスごとの専用セリフになります。
